# Change Log

All notable changes to the "PSScriptAnalyzer for VS Code" extension will be documented in this file.

## [0.0.1] - 2026-01-09

### Added
- **Initial Release:** Complete integration with the `PSScriptAnalyzer` module.
- **Real-time Diagnostics:** Instant "squiggly" highlights for PowerShell code quality and best-practice violations.
- **Smart Automation:** Background analysis triggers automatically on file open, tab switch, and save.
- **Multi-Shell Support:** Intelligent detection for both Windows PowerShell 5.1 and PowerShell Core (pwsh).
- **One-Click Onboarding:** Automatic detection of missing modules with a guided terminal installation.
